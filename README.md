# Python Day 136 - Count Vowels

## Description
This Python program counts the vowels in a word or sentence entered by the user.

**Output:** `Total vowels: 3`

## Concepts Used
- Strings
- For Loop
- If Statement
- lower()
- Counter Variable

## How to Run
Run `count_vowels.py` using Python and enter a word or sentence.
